The while loop checks available RAM while holding ram_lock. A job waits until enough RAM is available, 
then reserves the requested amount. This prevents the simulator from allocating more RAM than

3. Course Reflection (AI Engineering Context)

Understanding operating systems helps an MLOps Engineer run AI workloads reliably and efficiently.
 Process queues and scheduling help manage competing jobs, while RAM limits help prevent over-allocation 
 and thrashing. Deadlock avoidance keeps jobs from waiting indefinitely for GPUs, and file system checks 
 and permissions protect important datasets and model files. These concepts make it easier to diagnose 
 resource problems that cannot be solved by Python or PyTorch code alone.
